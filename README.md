# virix

> Meta-framework de vue

Una capa de convenciones opinionadas sobre Vue:

- File-based routing
- Auto-imports de composables y components
- Layouts
- SSR

## Status
En desarrollo activo

## Quick start

```bash
git clone https://github.com/devlusoft/virix
cd virix
pnpm install
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000)
